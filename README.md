# temp — sandbox

Scratch repo. Nothing here is meant to last, and anything in it can be wiped
without a second thought.

## What it's for

This is the front door for new Claude Code sessions. Sessions on the web always
start inside some repository, so this is the one I start in — then I ask Claude
to create a dedicated repo for whatever the actual project is, and the work goes
there instead.

The usual opening line is:

> Create a public repo called `nome-do-projeto` and build it there.

Claude creates it, pulls it into the session, and everything lands in the new
repo. This one stays empty.
